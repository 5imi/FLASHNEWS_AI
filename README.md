# FlashNews AI

Aplicatie mobila pentru agregarea, sintetizarea si redarea audio a fluxurilor de stiri, dezvoltata pentru platforma Android.

## Prezentare Generala

FlashNews AI este o solutie software conceputa pentru a facilita accesul rapid si organizat la informatii din surse multiple. Aplicatia structureaza continutul editorial intr-un flux vertical dinamic, include un modul de sinteza a evenimentelor principale si ofera suport pentru redare vocala prin tehnologia Text-to-Speech nativa.

## Functionalitati Principale

### 1. Agregare si Organizare de Continut
- Suport complet pentru fluxuri RSS si compatibilitate cu standardul OPML.
- Catalog organizat pe domenii de interes (economie, tehnologie, societate, actualitate).
- Cautare rapida si optiuni de urmarire a publicatiilor selectate.

### 2. Moduri de Utilizare si Accesibilitate
- Redare vocala fluenta a articolelor si sintezelor pentru utilizare fara interactiune manuala.
- Mod dedicat pentru lectura cu teme vizuale cu contrast ridicat si scalare tipografica.
- Afisare concentrata pe textul editorial, eliminand elementele decorative nespecifice.

### 3. Arhitectura Tehnica
- Dezvoltare nativa in Kotlin utilizand Jetpack Compose si componente Material Design.
- Structura modulara bazata pe principiile Clean Architecture (module separate pentru date, retea, baza de date si interfata).
- Baza de date locala Room pentru stocare sigura offline si management al preferintelor.

## Cerinte de Sistem

- Sistem de operare: Android 12 (API level 31) sau o versiune mai recenta.
- Mediu de compilare: Android Studio cu suport pentru Kotlin 2.0.
